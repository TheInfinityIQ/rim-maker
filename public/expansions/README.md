# Expansion symbols

Original, unmodified expansion-symbol textures extracted from the user's installed RimWorld 1.6.4871 `resources.assets`. The names correspond to the `ExpansionDef.iconPath` entries under `UI/HeroArt/ExpansionIcon_*`.
